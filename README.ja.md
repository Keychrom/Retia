# Retia

**English** | [日本語](README.ja.md)

**Zig 製、統合シェルを備えたスクロールタイリング Wayland コンポジタ。**

Retia は [niri](https://github.com/YaLTeR/niri) で知られるスクロール列タイリングの操作文法に、niri が意図的に持たない「統合デスクトップシェル」を組み合わせるプロジェクト。タスクバー、スタートメニュー、セッションをまたぐレイアウト復元を、コンポジタと一体で設計し、別プロセスとして分離する。

> ⚠️ **現状: 設計フェーズ。** 仕様 (v1.0) は凍結済み、実装はこれから。まだビルドできるものはなくリリースも無い——経過を見たい人は Watch を。

## 考え方: 3 層モデル

1. **操作文法は niri 互換。** スクロール列、consume/expel、niri のデフォルトキーバインド、KDL 設定、タッチパッドジェスチャ。筋肉記憶をそのまま引き継ぐ。この層で独自路線を捏造しない
2. **プロダクトで差別化: niri に無いシェル。** タスクバーとスタートメニューをファーストクラスの構成要素として持つ。「niri 式タイリングの DE」という生きている隙間を埋める
3. **シェルだからこそできる看板機能。** タスクバーに埋め込んだストリップ・ミニマップ（「無限スクロールのどこにいるのか分からなくなる」問題を解く）、セッションまたぎのレイアウト復元、起動と窓切替を 1 つの検索に融合したスタートメニュー

比較の座標軸: Hyprland は C++、niri / COSMIC / ShojiWM は Rust、sway は C。Retia は Zig 製のリッチシェル路線。

## v1.0 の予定機能

- **スクロール列レイアウト** — 窓を縦積みした列が横方向に無限連結。初日から滑らかなスクロールアニメーション
- **タスクバー** — ワークスペース、タスク一覧、時計、バッテリー、**ストリップ・ミニマップ**（トレイは後日）
- **スタートメニュー** — XDG アプリ一覧のあいまい検索が、実行中の窓へのジャンプも兼ねる
- **セッション永続化** — 列構造を再起動またぎで復元
- **KDL 設定**（niri 互換文法）+ ホットリロード、バリデーションエラーはシェル上に表示。実験的に Zig プラグイン拡張も
- **二面構成のバー** — 宣言的 KDL ウィジェット（`custom` スクリプトウィジェット含む）+ 実験的な Zig プラグインウィジェット
- デフォルト端末は **Kitty**。自作ターミナルは v1.0 以降に計画

## 技術スタック

- **コンポジタ**: [wlroots](https://gitlab.freedesktop.org/wlroots/wlroots) を Zig から駆動（手書きバインディング）
- **シェル**: layer-shell の別プロセスクライアント。自前の軽量レンダラ（OpenGL + freetype/harfbuzz）をバーとスタートメニューで共有
- **設定**: KDL 第一面 + Zig プラグイン（dlopen、実験的）
